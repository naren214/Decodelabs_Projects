# DecodeLabs Projects

Small command-line projects built with Python's standard library.

| Project | Run |
| --- | --- |
| To-do list | `python ToDoList_Project_1.py` |
| Expense tracker | `python ExpenseTracker_Project_2.py` |
| Secure password generator | `python SecurePasswordGenerator_Project_3.py` |
| General knowledge quiz | `python GKQuiz_Project_4.py` |

Run the expense tracker regression checks from this directory with `python -m unittest -v`.
